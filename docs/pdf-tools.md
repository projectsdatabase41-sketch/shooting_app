# PDF-инструменты (iLoveAPI)

Модуль в приложении: **Настройки → PDF-инструменты**. Обработка идёт на сервере
звонков, ключи iLoveAPI в приложение не попадают.

## Как работает

1. Приложение выбирает файлы и отправляет их на сервер (`POST /pdf/upload`),
   сервер держит их в R2 до окончания задачи.
2. `POST /pdf/run` с задачей и параметрами: сервер проходит цикл iLoveAPI —
   `auth` (публичный ключ проекта) → `start/<tool>` → `upload` → `process` →
   `download`, кладёт результат в R2 и возвращает идентификатор.
3. Приложение забирает результат (`GET /pdf/result/<id>`) и отдаёт на «Поделиться».
   Исходные файлы из R2 удаляются сразу.

Пять ключей проектов хранятся в секрете `ILOVEPDF_PUBLIC_KEY` (через запятую).
На каждый запрос ключ выбирается случайно, при отказе пробуется следующий —
лимит одного проекта не останавливает работу.

## Инструменты

Объединить (`merge`), разделить (`split`, `splitsmart`), сжать (`compress`),
Office → PDF (`officepdf`), HTML → PDF (`htmlpdf`), изображения → PDF
(`imagepdf`), PDF → JPG (`pdfjpg`), PDF/A (`pdfa`), номера страниц
(`pagenumber`), водяной знак (`watermark`), поворот (`rotate`), восстановление
(`repair`), пароль (`protect`), снятие пароля (`unlock`), проверка (`validate`),
вложения (`unpack`), правка (`editpdf`), OCR (`ocr`).

Подпись (`sign`) не подключена: у iLoveAPI она не входит в бесплатные кредиты.

## Проверено вживую (19.11)

Полный цикл на реальном ключе: `merge` двух PDF → результат 1117 байт с
заголовком `%PDF-1.4`; `compress` одного PDF → 796 байт. Все пять ключей
проходят `auth`. Очередь `delete` у iLoveAPI отвечает 404 — поэтому задачу не
удаляем отдельно, у них свой срок хранения.

## Лимиты

Бесплатно 2500 кредитов в месяц на проект (около 250 файлов): слияние,
разделение и поворот — 5 кредитов за файл, остальные инструменты — около 10.
С пятью ключами суммарно около 12 500 кредитов в месяц, при необходимости
добавляются новые ключи без обновления приложения.
