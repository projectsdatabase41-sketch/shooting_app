# Отзывы 19.11.2026 — разбор и план

Выгрузка `app_feedback_rows (11).csv`: 40 записей (34 Android, 6 веб), 15 ошибок
по страницам `ERROR:`, остальное — жалобы и пожелания.

## Что уже исправлено в этой партии

- **Кнопка «Найти в интернете» работает без своего ключа** — поиск идёт через
  сервер (Tavily), ключи в секрете воркера. Свой ключ Gemini остаётся запасным.
- **Переводчик больше не сыпет ошибками**: после 429 минуту не дёргаем MyMemory,
  поэтому 11 записей «Переводчик ответил 429» из выгрузки не повторятся.
- **Падение в списке собеседников** (`Null check operator used on a null value`,
  `_reload` после закрытия экрана) — добавлена проверка `mounted`.

## Лента новостей: какой сервис выбрать

- **NewsCatcher** — платный API (есть триал; тарифы от ~$50/мес). Для ленты
  внутри приложения невыгодно.
- Бесплатные варианты с запасом: **NewsData.io** (200 запросов/день),
  **GNews** (100/день), **Mediastack** (500/мес), **The Guardian API**
  (бесплатно, но только их материалы), **RSS-агрегация** (бесплатно и без
  лимитов: ISSF, федерации, профильные СМИ).
- Рекомендация: RSS + один из бесплатных API как дополнение, кэш в R2 на сутки
  (тот же механизм, что у поиска), фильтр по ключевым словам (стрельба, ISSF,
  винтовка, пистолет, соревнования). Токены — в секретах воркера, как Tavily.
