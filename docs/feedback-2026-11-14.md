## Как это устроено

- Пуш в `main` запускает три workflow: «Веб-версия на GitHub Pages», «Android APK»
  (релиз-тег `latest-apk` с `version.json`), «Переводы интерфейса».
- Деплой идёт по SSH-ключу (`git@github.com:...`), PAT для этого не нужен.
- `[no-apk]` в сообщении коммита — не собирать APK, `[skip ci]` — не запускать сборки.
