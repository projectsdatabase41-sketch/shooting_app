# 03. Проверки на устройстве

Всё ниже исправлено в коде, но требует реального прогона на двух устройствах:
сборка и тесты такого не показывают.

## Звонки (исправлено 20.11, коммиты 4d79263, 50cebc2)

1. Во время разговора нажать «Свернуть» — экран закрывается, звонок идёт
   дальше; вернуться в него из мини-баннера в чате.
2. То же системной кнопкой «назад».
3. Собеседник сбрасывает — звонок должен завершиться сразу, а не через ~19 с.
4. Свой превью камеры не должен быть зеркальным (большое и маленькое окно).

## «Кругляшок» (исправлено 20.11, коммиты f2bdbf3, 4da7a88)

1. Открыть запись «кругляшка» и переключить камеру **до** начала записи —
   превью должно остаться, чёрного экрана быть не должно.
2. Переключить камеру **во время** записи — видео должно продолжиться.
3. Выйти с экрана при открытой камере — приложение не должно падать
   (`releaseFlutterSurfaceTexture`).

## Вложения (исправлено 20.11, коммиты f73f0af, 03a13c3)

1. Отправить фото, закрыть чат и открыть заново — фото должно быть у
   собеседника без перезахода (приём работает без открытого экрана).
2. Отправить два файла подряд — оба уходят, второй не «висит».
3. Текст можно отправлять, пока файл ещё грузится.

## Push и звонки (подсказка в диагностике, 20.11)

1. Проверка сети с собеседником без push-адреса — отчёт должен прямо сказать,
   что тому нужно открыть приложение и разрешить уведомления.

## Как записать результат

Если что-то не работает — нужен отчёт «Диагностика сети» из приложения и
краткое описание: на каком шаге, на каком устройстве, что было на экране.
По этим данным правка превращается в конкретный коммит.
