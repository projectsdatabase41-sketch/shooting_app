# 05. ИИ-помощник выбора режима в PDF-инструментах

**Источник:** отзыв 19.11, 09:25 — «стоит добавить ИИ помощника, чтобы он сам
выбрал нужный режим».

## Что уже есть

- Экран «PDF-инструменты»: 19 задач (объединить, разделить, сжать, конвертации,
  номера страниц, водяной знак, поворот, восстановление, пароль, OCR, PDF/A и др.).
- Параметры под каждую задачу: уровень сжатия, диапазоны страниц, позиция
  номеров, текст и положение водяного знака, язык OCR, DPI, профиль PDF/A.
- Инструменты фильтруются по типу приложенных файлов: только PDF — конвертеры
  скрыты, не PDF — остаётся только «в PDF».
- Обработка идёт на сервере (iLoveAPI), ключ в приложении не хранится.

## Что осталось

1. Кнопка «Подсказать» на экране: отправляет на сервер только описание файлов
   (имена, расширения, размеры, число страниц если известно) и запрос
   пользователя словами («сожми для почты», «сделай один файл из двух»).
2. Ответ — одна из задач и её параметры; приложение подставляет их в форму и
   показывает объяснение одной строкой.
3. Ограничение: ИИ не трогает сами файлы, только выбирает режим; при
   неуверенности возвращает `null` и форма остаётся как была.
4. Если ответ не пришёл (нет сети, лимит) — тихо остаёмся на ручном выборе.

## Что нужно от пользователя

Ничего: логика самодостаточна. Нужна только проверка на реальных файлах после
реализации.

## Замечание по стоимости

Запрос короткий (без содержимого файлов) — один вызов модели на нажатие, без
фоновых обращений.
