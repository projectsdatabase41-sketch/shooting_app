# 02. Графики из данных приложения, а не из ответа модели

**Источник:** отзывы 19.11 — 12:24, 12:25, 12:27.

## Что не нравится пользователю

- «Графики сделал ужасные по тренировкам: везде результат 10.6, но уровни
  разные» — модель подставляет одно и то же число вместо фактических значений.
- «Лучше не учить ИИ создавать графики, диаграммы, круговые диаграммы, таблицы,
  а создать готовые инструменты для генерации кода для отображения нужных
  форматов, а ИИ будет просто их заполнять» — экономия токенов и надёжный вид.
- То же для данных тренировок: модель должна передавать нужные строки в готовую
  форму, а не сочинять разметку.

## Что уже сделано (20.11)

В подсказку модели добавлено правило: числа для графика брать только из данных,
при отсутствии разбивки не рисовать плоский ряд из одного числа. Это снижает
мусор, но не устраняет причину.

## Что сделано (21.11, коммит `ec409aa`)

Блок «Обзор» в статистике (`lib/widgets/analytics_bento.dart`,
`lib/painters/bento_painters.dart`) — четыре готовые формы, значения для
которых считаются сами из `Shot`, без участия модели: итог с дельтой по
динамике, серии (текущая против прошлой), габариты через squarify, средний
выстрел по месяцам (радар). Это перенос промпта AnalyticsBento
(см. `docs/ui-prompts-map.md`), а не подключение к ИИ — модели эти формы
пока не предлагаются.

## Что осталось

1. Описать в приложении набор готовых «форм» — `ShotSeriesChart`,
   `RingDistributionChart`, `SeriesTotalsTable`, `ComparisonBar`, — которые
   строят значения САМИ из `Session`/`Shot`, а не из JSON модели
   (три из четырёх уже есть в блоке «Обзор», осталось вынести их как
   самостоятельные виджеты и добавить таблицу сумм по сериям).
2. Модель выбирает форму и метрику (`form: "series_totals"`, `metric: "ring"`),
   без чисел в JSON. Числа подставляются из базы.
3. Приложение проверяет: если модель всё-таки прислала числа, при наличии
   данных они игнорируются в пользу вычисленных.
4. Ограничение: не больше 3 форм на ответ (как сейчас с графиками).

## Что нужно от пользователя

Одна конкретная тренировка (её id или дата + упражнение) и список метрик,
которые хотим видеть: результат по выстрелам, средняя точка попадания,
разброс, распределение по кольцам, суммы по сериям, сравнение серий и т.п.

## Как проверить

На этой тренировке попросить у ассистента график — значения на осях должны
совпасть с таблицей выстрелов в приложении.
