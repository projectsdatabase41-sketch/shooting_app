## Архитектура (решение)

1. **Подготовка на этом ПК (один раз).** Скрипт конвертации: `.stp` →
   - `*.glb` — упрощённая сетка для 3D (быстрый старт, вес в разы меньше STEP);
   - `*.png` — превью (программный рендер сетки без GPU: изометрия, плоское
     затенение, прозрачный/светлый фон), 600×450.
   - `catalog.json` — категория, название, размер, файлы, хеш, краткое
     описание из `Brief description.txt`.
2. **Хранилище.** R2 в бакете воркера; в приложение отдаётся НЕ адрес R2, а
   непрозрачный id (32 знака) — воркер `GET /models/index` и
   `GET /models/<id>/{preview|model}`. Ключи R2 остаются в секретах воркера.
   На диске — только шифротекст (AES-GCM, ключ в секрете воркера): даже при
   утечке бакета модели не читаются без секрета.
3. **Приложение.** «3D-модели» становится каталогом: сетка карточек с
   превью, поиск и фильтр по категориям; тап → существующий вьюер с id,
   который превращается в ссылку воркера внутри (пользователь её не видит).
   Превью кэшируются локально (повторно не качаются).
4. **Обновление каталога.** `catalog.json` лежит в R2; приложение берёт его
   при открытии модуля (и по кнопке «Обновить»), новый файл кладёт скрипт
   загрузки через админ-токен воркера.

## Порядок работ

1. Каталог + конвертация + превью на ПК (скрипты в `tools/`, вывод — в
   отдельную папку вне репозитория, чтобы не пух git).
2. Воркер: эндпоинты `/models/index`, `/models/<id>`, загрузка с админ-токеном,
   шифрование в R2.
3. Приложение: экран каталога, карточки с превью, фильтр по категориям, кэш,
   открытие во вьюере по id.
4. Загрузка 329 моделей и проверка на телефоне/в вебе.

## Ограничения и риски

- Конвертация 386 МБ STEP в WASM на ПК — минуты на файл; делаем пакетно,
  с логом и пропуском битых.
- `.m3d`/`.a3d` (Компас) OpenCascade не читает — эти 3 файла в каталог не
  попадут, если не найдётся конвертер (отдельно сообщить владельцу).
- Нужен деплой воркера владельцем (секрет шифрования + админ-токен).
- Исходные STEP остаются в каталоге как «полная» версия: превью и GLB — для
  быстрого показа, STEP можно скачать/открыть по желанию (как сейчас вьюер).
