# TURN для звонков: подключение и лимиты

Сервер звонков (`cloud/calls-worker`) сам выдаёт временные доступы Cloudflare
TURN в ответе `/ice`, если в его секретах есть ключ Cloudflare Realtime TURN.
В приложении ничего вводить не нужно: клиент берёт серверы из `/ice`, ставит их
первыми и сообщает о расходе.

## Что нужно сделать один раз (2 секрета)

Ключ создаётся в Cloudflare Dashboard → **Realtime** → **TURN** → Create.
Получаются два значения: **Turn Token ID** и **API Token**.

Дальше любой из двух путей.

**Через дашборд (без командной строки):**
1. Cloudflare Dashboard → **Workers & Pages** → `pusl-calls` → **Settings** →
   **Variables and Secrets**.
2. **Add** → тип **Secret** → имя `TURN_KEY_ID` → значение Turn Token ID → Save.
3. Ещё раз **Add** → **Secret** → имя `TURN_KEY_API_TOKEN` → значение API Token → Save.
4. **Deploy** (кнопка Deploy в правом верхнем углу воркера).

**Через wrangler (если авторизован):**
```powershell
cd cloud\calls-worker
npx wrangler secret put TURN_KEY_ID
npx wrangler secret put TURN_KEY_API_TOKEN
npx wrangler deploy
```

Проверка: в приложении Настройки → Диагностика сети (нужен режим разработчика) —
шаг «ICE-серверы» должен показать `TURN: 1, провайдер: cloudflare`, а шаг
«Бюджет TURN» — израсходованные гигабайты.

## Лимиты и защита от перерасхода

Cloudflare Realtime: **1000 ГБ трафика TURN в месяц бесплатно**, дальше $0.05/ГБ.
RealtimeKit (участнико-минуты) нам не нужен — мы его не используем.

Защита в три слоя, чтобы никогда не выйти за бесплатный объём:

| Слой | Где | Порог |
|---|---|---|
| Сервер перестаёт выдавать TURN | `cloud/calls-worker/wrangler.toml` → `CF_TURN_LIMIT_GB` | 800 ГБ из 1000 |
| Клиент не берёт TURN, даже если сервер выдал | `lib/services/call_service.dart` (в `/ice` фильтруются `turn:` при 95% порога) | 760 ГБ |
| Учёт расхода | `CallSession` раз в минуту и в конце звонка шлёт `POST /usage` с байтами relay-пар | — |

Итого запас ~240 ГБ (24% бесплатного объёма) на случай ошибок учёта.

Что происходит при исчерпании: новые звонки идут только напрямую (STUN), видео
за строгим NAT в этом месяце перестанет подниматься — но счёт не вырастет.
В диагностике это видно как `Бюджет TURN … порог близко`.

Если понадобится поднять порог — `CF_TURN_LIMIT_GB` в `wrangler.toml` и редеплой;
клиентский порог считается от того же числа автоматически.
