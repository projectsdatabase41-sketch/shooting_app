## 1. Меню с переключателями (промпт = тот же glass-dashboard)

Владелец просит не финансовый дашборд, из промпта нужен только приём «нижний ряд
кнопок-переключателей». Смысл в приложении: на экране тренировки мишень и
«крутилка» остаются на месте, а ниже — горизонтальная полоса, выбирающая
раздел: **Статистика / Выстрелы / Ассистент / Заметки / Тренер**. Сейчас на
телефоне все разделы свалены в одну длинную ленту (`target_screen.dart`,
мобильная ветка `for (final page in pages)`).

Реализация: полоса кнопок с горизонтальной прокруткой, состояние в
`_WorkspaceBodyState`; выбранный раздел показывается один, мишень и `_ShotWheelBar`
не двигаются. Та же полоса в правой колонке на десктопе/вебе.

## 2. Анимация голосового сообщения (промпт voice-input)

В промпте: круглая кнопка, при записи квадрат вращается, раскрывается полоса из
12 столбиков «частот», справа таймер `ММ:СС`. Переносим в композер чата: во время
записи показываем столбики (анимация по `AnimationController`, без случайных
скачков на каждом кадре — на вебе дешевле сглаженная функция) и таймер.

## 4. Отзывы, которые в эту итерацию НЕ входят

- **#1** «мессенджер не работает после загрузки переписки с Google Диска, приложение не отвечает» — нужен разбор восстановления, отдельная задача (возможно, тяжёлый импорт в UI-потоке).
- **#2** фильтры новостей — нужен выбор источников/рубрик, меняет серверный воркер (RSS-фильтр) и настройки.
- **#3** фоновая подгрузка новостей с ограничением скорости — отдельная задача по загрузке картинок.
- **#5, #10** падения «прошлый сеанс оборвался» — нужен отчёт Crashlytics с уже включённым сбором.
- **#7** «уголок пристрелки вообще не верный» — нужен разбор геометрии маркера пристрелки на конкретной мишени.
- **#11** «проработать промпты ИИ, формат ответов, экономия токенов» — отдельный заход по `ai_service`/`AiContext`.
- **#12, #13, #15** P2P: правка `5fd064a` уже в сборке; #13 — веб-версия **до** неё (20.11). Нужен прогон на двух устройствах.
- **#17** диагностика: шаги больше не врут, отчёт чистый — подтверждение, правки не нужны.
