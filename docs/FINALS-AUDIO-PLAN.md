# Звук финалов: толпа, реакции, реплики (план, 2026-10-21)

Статус: **только план, ничего не реализовано.** Основа уже есть: диктор (`lib/finals/announcer.dart`), заранее готовые записи (`voice_packs.dart`, `voice_texts.dart`), настройки ИИ-озвучки. Идеи владельца + мои дополнения (помечены «предложение»).

## 1. Идея
Финал звучит как живой зал: диктор (есть), реакции толпы на выстрелы, фоновый шум зала, отдельные реплики зрителей. Всё готовится заранее (генерация моделью или готовые звуки) и проигрывается без ожидания; без записей звука толпы нет (диктор как сейчас).

## 2. Дорожки (шины) — предложение
| Дорожка | Что | Приоритет |
|---|---|---|
| A. Диктор | команды, рейтинг | высший, толпа при нём приглушается |
| B. Реакции | разовые крики/смех/свист на события | средний |
| C. Фон | бесшовный шум зала в 3–4 уровнях накала | низший |
| D. Реплики | короткие фразы зрителей (список ниже) | средний |

Отдельные регуляторы громкости на каждую дорожку, общий выключатель «Атмосфера зала», отдельный — «Насмешки».

## 3. Как избежать резких склеек (главное требование)
- **Выстрелы идут подряд или почти одновременно** → события сначала собираются в **окно ~1,5 с**; на окно играется ОДНА реакция по самому значимому событию (не по реакции на каждый выстрел).
- Каждая запись: **короткая атака, длинный естественный хвост** (затухает сама), без обрезки на тишину; одинаковый «шум помещения» во всех записях, чтобы не было скачков фона.
- Если новая реакция приходит, пока играет прежняя, прежняя **не обрывается**, а плавно (0,3–0,5 с) приглушается; новая входит поверх. Одновременно не больше 3 голосов на дорожке B.
- Более сильная реакция может **кроссфейдом** заменить слабую; слабая поверх сильной — отбрасывается.
- Минимальная пауза между одинаковыми записями, случайный выбор из нескольких вариантов (не повторять подряд).
- **Дакинг:** при диктор/реплике фон −6…−10 дБ, возврат плавный (0,5–1 с).
- Фон — **бесшовные петли** одинаковой громкости (нормализация LUFS), смена уровня накала кроссфейдом 2–3 с.
- Все записи заранее нормализованы по громкости; ограничитель на общем выходе (чтобы наложения не клиповали).

## 4. События и уровни реакций
Уровень реакции: **средняя / высокая / сильная**. Пороги — настраиваемые параметры (значения ниже — стартовые, проверить на практике).

1. **Одинаковые результаты у части участников при одиночных выстрелах.** Доля участников с одним и тем же результатом в серии: **≥40% → средняя** (одобрительный гул «о-о», смешок), **≥90% → высокая** (общий вздох/рёв, овация).
2. **Сильный отрыв лидера.** Зависит от доли оставшихся участников: **осталось <50% → сильная** реакция, **>50% → средняя**. Размер «сильного отрыва» — порог в очках (предложение: ≥ 1,5–2,0; настраиваемо).
3. **Отмена выстрела («насмешка»).** Нажал не туда и отменил выстрел в финале → смех/«у-у-у» + при желании фраза из группы «отмена». Ограничение: не чаще раза в N секунд и не в пристрелке; выключатель «Насмешки».
4. **Накал по мере выбывания.** Параметр `heat` 0…1: растёт с долей выбывших (`выбыло / (участников − 2)`). Влияет на: уровень фона (C), громкость, шанс крика/свиста, переход средних реакций в сильные.
5. **Смена мест при отборе медалистов (высокий уровень).** Когда меняется распределение медальных мест (особенно перед последними выстрелами): «ааа!», шум, свист, овация. Самая сильная реакция в финале.
6. *(предложение)* **Выбыл участник** — короткий протяжный «у-у-у»/аплодисменты (для бота и человека одинаково).
7. *(предложение)* **Выстрел-десятка / 10,9** — одобрительный гул, свист; **выстрел-провал** — вздох.
8. *(предложение)* **Тишина перед решающим выстрелом** — фон уходит на минимум на 2–3 с, затем реакция.
9. *(предложение)* **Победитель** — финальная овация (длинная, с плавным затуханием).

## 5. Реплики зрителей (~40, черновик; доработает владелец)
Использовать «по смыслу» чаще, «по приколу» иногда (сбить с толку), без имён участников. Все фразы — отдельные короткие записи; доля «по приколу» ~10–15% (настраиваемо).

**Подгонка перед выстрелом:** «Нажимай!», «Дёргай!», «Давай-давай!», «Не тяни!», «Время!», «Что ты ждёшь?», «Спокойно…», «Дыши!», «Ну же!», «Целься лучше!»

**После хорошего выстрела:** «Вот это да!», «Десятка!», «В яблочко!», «Красавчик!», «Ничего себе!», «Так держать!»

**После ровного/среднего:** «Ну понятно», «Бывает», «Так себе», «Ровненько», «Один в один!», «Скучно, давайте острее!»

**После плохого:** «Ну куда ты?!», «Мимо кассы!», «Ой-ой», «Куда смотрел?», «Тряхнуло, да?», «Это что было?»

**Отмена выстрела (насмешка):** «Не туда нажал, да?», «Кнопки перепутал?», «Отмена-отмена!», «Передумал?», «Руки дрожат?», «Ну вот, теперь заново»

**Накал:** «Осталось двое!», «Напряжение!», «Тишина в зале…», «Решающий!», «Кто возьмёт золото?», «Медаль рядом!»

**«По приколу» (случайно, чтобы сбивать с толку):** «Чайку бы сейчас», «А который час?», «Я на секунду отвлёкся», «Мне показалось?», «Это точно финал?», «Тише, тише!»

Правила: без мата и оскорблений конкретного человека; насмешки над отменой — добродушные; выключатель «Реплики».

## 6. Фоновые разговоры, свисты, крики (отдельная дорожка)
- Фон C: разговоры без имён и разборчивых фраз («бормотание зала»), шорохи, кашель, редкие хлопки — **3–4 уровня накала** (спокойно → оживлённо → напряжённо → кульминация).
- Разовые вставки на B: свист (одиночный/групповой), «а-а-а», рёв, аплодисменты разной длины, смех, вздох, «у-у-у».

## 7. Состав записей и объём (оценка, проверить)
- Реакции: 4–6 вариантов на каждый вид × 3 уровня → порядка 60–80 клипов по 1–4 с.
- Реплики: ~40 клипов по 1–2 с; можно по 2 «голоса» на фразу.
- Фон: 4 петли по 20–40 с.
- Формат: моно, ~64–96 кбит/с (mp3/ogg); весь набор в пределах нескольких МБ — **измерить**; загружаемый пакет (не в APK), чтобы не раздувать приложение.

## 8. Откуда звуки — открытые вопросы
- Генерация толпы моделью: есть сервисы звуковых эффектов по тексту; **доступность, цена и качество проверить** (в проекте пока подключена только озвучка речью). Альтернатива — готовые звуки с проверенной лицензией (для коммерческого использования). Не использовать записи с чужими голосами/правами без разрешения.
- Реплики зрителей — озвучка речью (как диктор), разные голоса и «шумный» эффект зала.
