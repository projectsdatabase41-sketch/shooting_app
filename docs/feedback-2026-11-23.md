## Восстановление переписки: причина ANR и правка

Причина «приложение не отвечает» после восстановления: на КАЖДОЕ сообщение
делались `COUNT(*)` (`refreshTotalUnread` внутри `addMessage`) и поиск по
`client_message_id` по всей таблице (индекса нет), а `jsonDecode`/`base64` шли
в главном изоляте; вставка — по одной строке, без прогресса и отмены. После
обрыва курсор не двигался, и при следующем входе выкладка гнала историю заново.

Сделано:

- восстановление с Диска: пачки по 100 сообщений одной транзакцией, дедупликация
  одним `SELECT`, разбор индекса и base64 — через `compute`, один
  `refreshTotalUnread()` на пачку, `await` между пачками; прогресс «N из M» и
  отмена, недобранная пачка дописывается; флаг `chat_gdrive_restored` (повтор
  только по кнопке), курсор двигается за восстановленное;
- защищённая папка Nexus: пачки по 50, шифрование пачки одним `compute`,
  курсор по каждой записанной записи, фон-проход не дольше 8 секунд;
- экран резервных копий: окно прогресса с «Восстановлено N из M» и кнопкой
  «Отмена», понятные сообщения при ошибке, подтверждение повторного импорта.

## Маркер пристрелки

Был бейдж «Пристрелка» в правом верхнем углу виджета (не на бланке), его же
накрывали кнопка отмены выстрела и подпись суммы. Теперь уголок рисует
`TargetPainter`: вершина прямого угла = угол бланка (та же точка, что пробоина
в мм `+R,+R`), катеты внутрь, золото с авто-контрастным контуром, поверх колец;
при зуме/панораме прижимается к краю видимой области. Плашка с холста убрана,
в финалах осталась только подпись. Проекция мм↔px теперь одна на пробоины,
черновик и маркер — проверено тестом `test/target_painter_test.dart` (6 кейсов).
