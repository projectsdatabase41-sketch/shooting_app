ОЗВУЧКА ФИНАЛОВ — тексты для записи голосом
==========================================

Что это. Приложение сейчас говорит команды финала синтезатором телефона. Здесь лежат тексты команд,
чтобы вы озвучили их хорошим голосом (ИИ) и положили рядом. Пока записи не подключены в приложение,
оно продолжает говорить по-старому; подключение записей — отдельный шаг (скажите, когда файлы будут готовы).

Как озвучивать.
1. Выберите язык: папки ru, en, de, zh (в каждой тексты на этом языке; переводы английский/немецкий/китайский
   сделаны мной как типовые стрелковые команды — прослушайте и поправьте при необходимости, текст в .txt).
2. В каждой папке: 1_commands (команды), 2_standings (слова для рейтинга), 3_places (места), 4_numbers (числа).
3. Для каждого файла <имя>.txt сделайте запись <имя>.mp3 (или .wav) и положите В ТУ ЖЕ папку, рядом с .txt.
   Имена не меняйте — по ним приложение найдёт запись.
4. Все фразы одним списком — в файле _all.txt каждого языка (удобно загрузить в сервис озвучки пачкой).
5. Один и тот же голос и скорость для всех файлов языка; без лишней тишины в начале и конце (до 0,2 с).
6. Новый язык: скопируйте папку ru под кодом языка (например es), переведите тексты в .txt, озвучьте.

Что НЕ озвучивается записями. Имена участников («Лидирует Иванов») остаются голосом телефона: их нельзя
записать заранее. Составные фразы приложение собирает из записей:
  «Лидирует» + имя + число;  «Второй» + имя + число;  «Выбывает» + имя;  «Четвёртое место» и т. д.
Числа (счёт вида 105,3) собираются из записей 4_numbers: сотни + десятки/до 19 + «запятая» + десятая доля.

Команды финала по порядку:
  Пристрелка  ->  Заряжай  ->  Старт  ->  Стоп  ->  (рейтинг после «Стоп»)  ->  Финал окончен.

Размер файлов: коротко, 1–2 с на фразу. Весь набор одного языка — 51 файл.
