# Shooting App

Приложение для стрелкового спорта (Flutter, Android + Windows) — запись,
просмотр и анализ результатов стрельбы по спортивным мишеням ISSF.

Полная постановка задачи — в проекте Claude ("Программа по спортивной
пулевой стрельбе"), документы `tech-spec-v2.md`, `logic-personalization-spec.md`,
`dev-task-spec.md`, `implementation-notes.md`.

## Первый запуск (ВАЖНО — прочитать перед `flutter run`)

Код написан и вручную вычитан без доступа к реальному Dart SDK в среде
разработки (сеть до `dl.google.com`/`pub.dev` заблокирована в этом
контейнере — см. `implementation-notes.md`, раздел "Известные
ограничения"). Поэтому **первый запуск на вашей машине — обязательный
шаг приёмки**, а не формальность:

```bash
flutter create --platforms=android,windows .   # если ещё нет платформенных папок
flutter pub get
flutter analyze
flutter test
flutter run -d windows      # или flutter run -d <android-device>
```

Ожидаемо: мелкие синтаксические ошибки (опечатки, несовпадение сигнатур
API между версиями Flutter/пакетов) — при первом запуске это нормально,
не признак того, что архитектура ошибочна. Правьте по месту — код
организован так, что ошибка в одном файле не должна требовать
переписывания соседних.

## Структура

См. `dev-task-spec.md` задача 0.2 — модули `models/ state/ services/
screens/ widgets/ painters/ db/` строго разделены, UI никогда не делает
SQL напрямую (только через `services/LocalDbService`).

## Что реализовано

Все 4 блока `dev-task-spec.md` (данные, персонализация цвета, логика
тренировки, роли/комментарии) плюс экраны. Подробности и обоснования
решений по трём открытым вопросам (кнопки на экране правки, кнопка
"Помощь"→"Заметка", состав нижней навигации) — в `implementation-notes.md`.

## Что осознанно не реализовано

Раздел 12 tech-spec-v2.md — реальное подключение к Supabase, Management
API для одношагового подключения, реальное чтение тренера по токену,
многоязычность, iOS-сборка. Все точки расширения подготовлены (интерфейс
`SupabaseService`, RPC в `sql/schema.sql`) так, чтобы не требовалась
переработка вызывающего кода.
