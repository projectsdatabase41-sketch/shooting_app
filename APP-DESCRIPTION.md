# Pusl (shooting_app) — описание приложения

Состояние на 21 сентября 2026, версия 0.2.0. Это обзор «что это и что
умеет». Подробное поведение и алгоритмы (подсчёт очков, геометрия мишеней,
жесты) — в `TZ-current.md` (зафиксирован 5 сентября, чат, вложения через
Диск, режим разработчика и часть ассистента появились позже — они описаны
здесь).

## 1. Что это

Приложение для спортивной пулевой стрельбы: запись выстрелов по мишеням
ISSF, разбор результатов, дневник тренировок, ИИ-ассистент и общение
спортсмен ↔ тренер. Ключевая идея: выстрел хранится не числом очков, а
**координатами пробоины в миллиметрах** — из них считаются очки, средняя
точка попадания, кучность и направление увода, а тренировку можно
пересчитать под другую мишень.

Приложение не тренирует и не оценивает от себя, не мешает стрелять: любая
автоматика, способная помешать записи выстрела, отключена в пользу записи.

## 2. Кто пользуется

- **Спортсмен** — ведёт тренировки, видит историю и статистику, общается с
  ассистентом и тренером.
- **Тренер** — по выданному спортсменом токену смотрит его дневник,
  оставляет комментарии и заметки, пишет в личный чат, (в разработке)
  выдаёт задания.

Режим переключается в настройках. Приложение стартует полностью пустым, без
демо-данных.

## 3. Платформы и доставка

| Платформа | Как получить |
|---|---|
| Web (PWA) | автосборка GitHub Actions → GitHub Pages при каждом push в `main` |
| Android APK | автосборка GitHub Actions → GitHub Release `latest-apk` (стабильная ссылка) |
| Windows | `flutter run -d windows` |
| iOS | только веб-версия как PWA на домашнем экране |

Стек: Flutter 3.38 / Dart 3.11, локальная SQLite (`sqlite3`, в вебе —
IndexedDB), состояние через Provider. Облако — Supabase (свои проекты
пользователей + один общий проект чата). Ключи OpenRouter вшиваются в
сборку через секреты GitHub (`OPENROUTER_KEY` … `_4`).

## 4. Основные разделы (вкладки)

Состав вкладок настраивается (плитки или страницы), «Мишень» и «Настройки»
скрыть нельзя.

**Спортсмен:** Упражнения · Мишень · Статистика · Ассистент · Мессенджер ·
Настройки, плюс свои плитки сервисов.
**Тренер:** Дневник · Спортсмены · Статистика · Ассистент · Задания ·
Мессенджер · Настройки.

### Упражнения и тренировки
Упражнение = мишень + серии (зачётные и пристрелочные) + лимиты времени.
Тап по упражнению открывает список его тренировок; у тренировки есть
состояния (не начата / идёт / пауза / завершена), таймеры, корзина с
восстановлением и «тренировка-призрак» для сравнения.

### Мишень
Четыре мишени ISSF (винтовка/пистолет 10 м, м/к винтовка 50 м, пистолет
25 м). Экран мишени — щипок = зум, двумя пальцами по вертикали = листать
выстрелы, перетаскивание пробоины при правке, колесо десятых, компас для
направления. Новый выстрел создаётся только кнопкой под мишенью (тап и
долгое нажатие на самой мишени убраны сознательно — конфликтовали с
жестами). В углах бланка показаны результат, сумма, координаты X/Y и
направление выбранного выстрела.

### Статистика и разбор
Суммы, средние, кучность, графики динамики, аналитическая панель; просмотр
прошлой тренировки на той же мишени.

### Ассистент (ИИ)
Чат на OpenRouter с цепочкой бесплатных моделей и запасными ключами.
Понимает контекст тренировок, умеет строить графики (блок ```chart).
**Справочные базы:** общая база разработчика (книги, правила) + личные
таблицы пользователя из его Supabase; ассистент ищет по ключевым словам и
видит до 6 кусков на таблицу (до 2000 символов каждый, 14000 всего),
дату записи и текущее время. При подключении личной таблицы ИИ сам
описывает, что это за таблица (пустую — только по структуре, содержимое
дописывается позже). Есть память о пользователе.

### Сервисы (свои плитки)
Пользователь подключает внешний источник (ссылка/JSON/curl, Airtable,
Supabase, заметки…), ИИ подбирает вид отображения записей (заголовок /
кратко / подробно) и плитка появляется на главном экране.

### Импорт и фото
Импорт из SCATT (см. `docs/scatt-import-guide.md`), «Фото мишени» с
камеры: детектор находит мишень и пробоины (чистый Dart, без OpenCV).

### Облако и тренер
Личная база Supabase пользователя (вход по почте) — синхронизация
тренировок. Доступ тренеру выдаётся токеном; тренер видит дневник и
комментирует.

## 5. Мессенджер

- **Общий чат** — одна лента для всех пользователей, ответы, графики,
  перевод сообщений.
- **Личный чат 1:1** — транзит через общий проект Supabase: сервер держит
  сообщение только до получения, история живёт локально у обоих.
  Правка/удаление, ответ, множественное выделение, перевод (MyMemory),
  push через Firebase.
- **Вложения** — фото (сжатие до 1600 px) и файлы до 50 МБ через
  Supabase Storage. **Большие файлы (до нескольких ГБ)** — долгое нажатие
  на скрепку: файл грузится с устройства прямо в выделенный Google Drive
  (короткоживущий токен выдаёт Edge Function `chat-drive-token` через
  Apps Script), получатель видит кнопку «Скачать», после скачивания файл
  на Диске стирается. Байты файла Supabase и Apps Script не видят.
- **«Позвать тренера»** — кнопка в личном чате: тренеру приходит громкий
  push (рингтон + вибрация, отключаемо в настройках чата), он отвечает
  «Иду» или игнорирует, спортсмен может отменить вызов (виден как
  пропущенный).

## 6. Оформление

Светлая/тёмная тема, пресеты цветов приложения (Графит, Хаки, Ночь, Кофе,
Светлый, Мята), выбор цвета круговой палитрой HSV / HEX, отдельная
настройка цветов мишени и пробоин, оформление пузырей чата.

## 7. Режим разработчика

Скрытый флаг (7 нажатий на заголовок «Настройки» → пароль), прячущий
недоделанное от обычных пользователей: вкладки «Мессенджер» и «Задания».
Выключен по умолчанию, работает в обоих режимах отображения вкладок.

## 8. Внешняя инфраструктура (вне репозитория приложения)

| Что | Где |
|---|---|
| Чат-проект Supabase | схема `sql/chat-schema.sql` (накатывается вручную, идемпотентна) |
| Edge Functions | `send-chat-push` (FCM), `chat-drive-token` — деплой `supabase functions deploy … --project-ref frbptucrvmyikencyspu` |
| Apps Script на отдельном Диске | `google-apps-script/chat-drive-relay.gs` |
| CI | `.github/workflows/deploy-web.yml`, `build-apk.yml` |

## 9. Что не доделано / осознанные ограничения

- Мессенджер и «Задания тренера» — под флагом разработчика; «Задания» даже
  не начаты.
- Тап по точке выстрела на мишени не поддержан (см. раздел «Мишень»).
- Вложения через Диск: только личный чат, только Android/Windows (в вебе
  нет пути к файлу на диске), общий лимит Диска 15 ГБ на всех.
- Веб: база живёт в IndexedDB браузера (очистка сайта = потеря данных),
  без фоновой работы и push.
- Большая передача через Диск: токен Google живёт ~1 час, ротировать
  чаще средствами `ScriptApp.getOAuthToken()` нельзя.
- Экранных тестов мало; проверка в основном `flutter analyze` + юнит-тесты
  логики и живой прогон в браузере.
